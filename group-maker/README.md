# 모둠 편성기 (Group Maker)

학생 인원수(또는 번호)와 모둠 개수(또는 모둠당 인원수)를 입력하면 무작위로 모둠을 나눠주는 웹앱입니다.

## 사용 방법

1. 학생 인원수를 입력하거나, 결석생 등을 제외하고 싶다면 학생 번호를 직접 입력합니다. (예: `1,2,3,5,7,9,10`)
2. "모둠 개수로 나누기" 또는 "모둠 인원수로 나누기" 중 원하는 방식을 선택합니다.
3. 값을 입력하고 "모둠 편성하기"를 누르면 무작위로 모둠이 구성됩니다.
4. "다시 섞기"를 누르면 같은 학생 목록으로 다시 무작위 편성할 수 있습니다.

## 배포

순수 HTML/CSS/JS로 작성된 정적 웹앱이라 별도 빌드 과정 없이 Vercel 등에 바로 배포됩니다.
